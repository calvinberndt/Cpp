Why Virtual Destructor?

WITHOUT virtual ~Person()
Person* p = new User("Alice", "pwd", 100);
delete p; // Only calls ~Person()
// MEMORY LEAK! account never deleted
WITH virtual ~Person()
Person* p = new User("Alice", "pwd", 100);
delete p; // Calls ~User() first
// SAFE! No memory leak

Memory Management

Rule of Three and dynamic array growth with exponential doubling.

Rule of Three

User Class
// 1. Constructor
User(name, pwd, bal) {
account = new BankAccount(bal);
}
// 2. Copy Constructor (DEEP COPY)
User(const User& orig) {
account = new BankAccount(*orig.account);
}
// 3. Destructor
~User() {
delete account;
}
